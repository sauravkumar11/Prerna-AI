# Development Guidelines

## Core Principles

- Preserve existing functionality.
- No large-scale rewrites.
- One version at a time.
- Test before merging.
- Production-ready code only.
- Prefer refactoring over rewriting.

## Branching

main

Stable releases.

develop

Integration branch.

feature/*

Feature development.

## Commit Messages

Examples

feat(memory): add semantic memory index

fix(browser): reconnect Chrome session

refactor(core): simplify planner

test(memory): add regression tests

docs(roadmap): update milestones
